# Murtaza 🦜

Claude Code için piksel sanatı bir sultan papağanı modu.

- Kendi panelinde, istem kutusunun üstünde ve son yanıtın üstünde görünür.
- Mesajlara göre tepki verir: teşekkür → kalp, "dans" → dans, "darı" → yemek, "iyi geceler" → uyku, "olmadı" → üzülme.
- Araç hatalarında ve yarıda kalan yanıtlarda üzülür, testler geçince dans eder.
- Düğmeler: Sev ♥, Darı ver, Dans et ♪, Uyut/Uyandır, Gizle. `/murtaza` gösterir / gizler.

## Kurulum

```
/plugin install murtaza --marketplace <kullanıcı>/murtaza
```

## Geliştirme

```
claude plugin validate .
claude plugin test .
```
